# 问题管理字段字典（PostgreSQL DDL提取）

数据库已确定PostgreSQL，语法按14+兼容设计，部署版本及字段长度待确认；草稿与提交的条件必填、角色可编辑范围以详设和接口契约为准。


## im_issue

|字段|数据库类型|可空|说明|
|---|---|---|---|
|id|UUID|否|应用生成UUID，接口字符串|
|tenant_id|VARCHAR(64)|否|从认证上下文取得|
|org_id|VARCHAR(64)|否|归属事业部|
|project_id|VARCHAR(64)|否|归属项目|
|issue_no|VARCHAR(64)|否|业务编号，编号规则待确认，不得MAX+1|
|title|VARCHAR(100)|否|问题概述|
|severity|VARCHAR(1)|是|S/A/B/C，草稿可空|
|status|VARCHAR(20)|否|DRAFT/PENDING_REPLY/REPLIED/CLOSED|
|description|TEXT|是|问题描述，应用限制10000字符|
|suggested_solution|TEXT|是|建议方案，应用限制10000字符|
|source_type|VARCHAR(20)|否|ANNOTATION/ROOM/IMPORT|
|source_ref|VARCHAR(128)|是|来源幂等键：批注ID或导入任务+行号；人工创建用请求键|
|review_id|VARCHAR(64)|否|评审单ID，外部引用|
|room_id|VARCHAR(64)|否|评审房间ID，外部引用|
|room_no|VARCHAR(100)|否|房间编号快照|
|baseline_id|VARCHAR(64)|是|基线稳定ID|
|baseline_no|VARCHAR(128)|是|基线编号快照|
|model_version|VARCHAR(64)|是|数模版本快照|
|report_id|VARCHAR(64)|是|评审报告稳定ID|
|report_name|VARCHAR(255)|是|报告名称快照|
|annotation_id|VARCHAR(64)|是|数模批注ID|
|raiser_id|VARCHAR(64)|否|提出人稳定ID|
|raiser_name|VARCHAR(100)|否|提出人姓名快照|
|handler_id|VARCHAR(64)|是|当前处理人ID，草稿可空|
|handler_name|VARCHAR(100)|是|当前处理人姓名快照|
|tc_uid|VARCHAR(128)|是|TC问题对象UID|
|tc_sync_status|VARCHAR(16)|否|NOT_SYNCED/PENDING/SUCCESS/FAILED|
|tc_synced_version|BIGINT|否|TC已确认的最大业务版本|
|version|BIGINT|否|乐观锁版本，每次业务写入递增|
|submitted_at|TIMESTAMPTZ(3)|是|首次提交时间|
|closed_at|TIMESTAMPTZ(3)|是|最近关闭时间，激活时清空|
|created_by|VARCHAR(64)|否|通用审计/技术字段，见详设|
|created_at|TIMESTAMPTZ(3)|否|通用审计/技术字段，见详设|
|updated_by|VARCHAR(64)|否|通用审计/技术字段，见详设|
|updated_at|TIMESTAMPTZ(3)|否|通用审计/技术字段，见详设|
|deleted_at|TIMESTAMPTZ(3)|是|仅草稿允许逻辑删除|
