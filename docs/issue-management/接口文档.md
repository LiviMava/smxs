# 问题管理接口文档 v0.2

> 2026-11-07，评审稿；由 generate_contract.py 与 yapi.json 同源生成。

## 通用约定

评审稿v0.2，所有规则为待确认设计。认证上下文取得用户、租户、组织授权；不信任客户端身份。
所有查询及文件下载同时校验租户、项目/房间授权和参与者权限。无权访问对象按404处理。
写接口要求Idempotency-Key；同键同请求重放原结果，同键异请求409。更新必须带version；冲突409且不产生历史/通知/TC事件。
HTTP 200成功；400参数错误，401未认证，403无操作权限，404不可见/不存在，409版本/状态/幂等冲突，413文件过大，415文件类型不支持，422业务规则不满足，503依赖暂不可用。
错误响应：{"code":"ISSUE_VERSION_CONFLICT","message":"数据已更新，请刷新","traceId":"示例追踪ID","data":null}。
业务提交成功仅代表本地事务成功，tcSyncStatus=PENDING表示等待异步同步，不等于TC已成功。

所有ID为字符串；时间为ISO8601；空值使用null，数组无结果返回[]。请求禁止未声明字段。

JSON Schema中的条件必填请同时阅读业务说明，服务端必须实现；本稿不把条件规则简化成全部字段必填。

## 分页查询问题列表

`GET /api/v1/issues`

bucket默认TODO。TODO=当前角色有待执行动作；DONE=历史参与且当前无待执行动作；ALL=授权范围内曾参与问题。DONE不等于CLOSED。固定updatedAt DESC,id DESC排序。counts复用筛选但不受bucket及分页影响。

|查询字段|要求|示例|
|---|---|---|
|bucket|TODO/DONE/ALL，默认TODO|TODO|
|keyword|问题编号或概述包含匹配，最多100字符；转义LIKE通配符||
|baselineNo|基线编号包含匹配，最多128字符||
|roomNo|房间编号包含匹配，最多100字符||
|status|DRAFT/PENDING_REPLY/REPLIED/CLOSED||
|severity|S/A/B/C||
|projectId|已授权项目ID，不扩大权限||
|page|正整数，默认1|1|
|pageSize|1..100，默认20|20|
